refactor: convert pkg/nmlite to read-only network monitoring

Convert the pkg/nmlite package from a read-write network management
system to a read-only network monitoring system. All operations that
modify network interface configuration have been removed while
preserving read capabilities for monitoring and display.

Changes:
- Remove all network interface write operations
- Delete static config manager, DHCP client, and sysctl operations
- Keep only read operations for monitoring network state
- Network configuration must now be done via OS tools (NetworkManager,
  systemd-networkd, etc.)

Deleted files (3):
- pkg/nmlite/static.go (150 lines)
- pkg/nmlite/dhcp.go (180 lines)
- pkg/nmlite/link/sysctl.go (50 lines)

Modified files (5):
- pkg/nmlite/interface.go (~450 lines removed, 17 methods deleted)
- pkg/nmlite/manager.go (~50 lines removed, 3 methods deleted)
- pkg/nmlite/link/manager.go (~380 lines removed, 15 methods deleted)
- pkg/nmlite/link/netlink.go (removed SetMTU method)
- pkg/nmlite/jetdhcpc/client.go (simplified ensureInterfaceUp)

Code reduction: 1,260 lines removed (64% reduction)

What still works (read operations):
- Reading network interface state (up/down/online)
- Reading IP addresses (IPv4/IPv6)
- Reading MAC addresses, routes, gateways
- Reading DHCP leases from system files
- Monitoring interface state changes
- All RPC read operations

What no longer works (write operations):
- Modifying IP addresses, routes, gateways
- Starting/stopping DHCP clients
- Renewing DHCP leases
- Modifying sysctl settings
- Bringing interfaces up/down
- Applying network configuration changes

Benefits:
- Simpler codebase (64% code reduction)
- Fewer bugs (no network modification edge cases)
- Better separation of concerns
- Safer operation (cannot misconfigure network)
- Better OS integration

All tests pass. No compilation errors.
